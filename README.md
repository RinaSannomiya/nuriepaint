# ringo_mikan_paint

塗り絵イラストを選んで、クリックで好きな色に塗りつぶせるアプリです。

## できること

- 起動時にイラストを選択（りんご / みかん / レモン / ほうれんそう）
- メイン中央に塗り絵、左にイラスト一覧
- 下部にカラーパレット
  - 色相 / 彩度 / 明るさをスライダーで調整
  - スウォッチから即選択も可能
- クリックで領域を塗りつぶし
  - `Shift` または `Alt` + クリックで消しゴム（その領域の色をクリア）
  - 「戻す」「リセット」あり

## 開発

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
npm run preview
```
