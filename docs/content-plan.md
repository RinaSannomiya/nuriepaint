# ローンチ素材計画（たたき台）

方針
- 全年齢向け。キャラ的な素材は残し、大人にも通る素材を足す。
- 正解の色がないテーマ（スイーツ・のりもの・もよう・ファンタジー）は「娯楽」として大事に残す。
- 正解の色があるテーマ（国旗・信号旗・道路標識・リアルな生き物）は「まなぶ」に使う。
- リアルな生き物は、ひろげるで「学習用ぬりえ」としてアップロードするときの**お手本**を兼ねる。
  → 線画＋見本画像（色付き）のペアで作り、アップロード形式と同じにそろえる。
- 同じテーマの「かんたん版（線が太い・領域が少ない）」と「こまかい版」を用意する（ちょう・ウミガメで実績あり）。

## 削る・まとめる

- どうぐ（`tool-01`〜`tool-05`）: 削除。
- さかな（`fish-05`）: 名前が汎用的なので削除候補。
- ごはん（`food-01`〜`food-05`）: 削らず、「たべもの」の中にまとめる。
- 1枚だけのカテゴリー: 柱に吸収する（やさい、はちゅうるい、でんしゃ、ひこうき、ふね、くるま）。
- カテゴリーIDは DB に残るので、IDは変えず、表示上のまとめ方だけ変える。

## 制作ルール（生成前に決める）
- 線の太さ、領域の数（かんたん／ふつう／こまかい）、背景なしを統一する。
- 塗りつぶしが成立するよう、**線が閉じている**ことを必ず確認する。
- まなぶ用は、線画と見本画像（色付き）を同じ構図・同じ大きさで作る。

## 削る素材の保存作品をバックアップする手順

保存作品は `colorings` テーブルの `illustration_id` と R2 の `object_key` に残っている。
Cloudflareにログインした環境（`npx wrangler login` 済み）で実行する。

```bash
# 1. 削る素材の保存作品を一覧にする（fish-05 を削らないなら IN から外す）
npx wrangler d1 execute ringo-mikan-paint-db --remote --json --command \
  "SELECT id, user_id, title, illustration_id, object_key FROM colorings WHERE illustration_id IN ('tool-01','tool-02','tool-03','tool-04','tool-05','fish-05')" \
  > backup-list.json

# 2. 一覧の object_key ごとに、R2 からダウンロードする
npx wrangler r2 object get "ringo-mikan-paint-artworks/<object_key>" --remote --file "backup/<id>.png"
```

削除したあとも、保存済みの画像（PNG）自体は R2 に残る。
ただし、マイギャラリーから元のイラストを開き直す導線は切れる可能性があるので、削除前に動作確認する。
